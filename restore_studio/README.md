# 🎨 Restore Studio

Комбайн для реставрации и обработки фотографий в ComfyUI.
Собирает в одной ноде то, что обычно требует десяти: чистка,
цветокоррекция, восстановление лиц, раскраска, апскейл.

---

## ✨ Что умеет

### 🔬 Реставрация
- **auto_wb** — автобаланс белого. Убирает желтизну и синеву.
- **auto_levels** — автоуровни. Растягивает контраст по перцентилям.
- **denoise** — шумоподавление. Убирает зерно и цифровой шум.
- **despeckle** — удаление точек и мелких царапин.

### 👤 Восстановление лиц
- **face_restore** — через ReActor (CodeFormer / GFPGAN).
- **face_restore_strength** — насколько сильно применять.
- **face_restore_sharpen** — авторезкость ПОСЛЕ restore.
  Компенсирует «пластиковость» GFPGAN.

### 🎨 Раскраска
- **colorize** — раскраска ч/б через DDColor.
- **colorize_strength** — 0.5 приглушённо, 1.0 полностью.

### 🎛 Цвет и тон
- **brightness / contrast / saturation / sharpness**
- **rgb_r / rgb_g / rgb_b** — цветовой оттенок (теплее/холоднее).

### 📐 Апскейл
- Модель подключается **снаружи** через `UpscaleModelLoader`.
- **upscale_scale** — во сколько раз увеличить (1.0 – 4.0).
- **upscale_sharpen** — резкость ПОСЛЕ апскейла (обычно 0).

### 🎁 Пресеты
- **📷 Old B&W Photo** — старые ч/б снимки с раскраской.
- **👤 Portrait** — портреты с face restore.
- **🏞 Landscape** — пейзажи с усиленным контрастом.
- **🎞 Film Look** — тёплое кинематографичное.
- **📼 Vintage** — выцветший винтаж.
- **✋ Manual** — всё вручную.

### 🖥 Live Preview
Отдельная нода. Показывает результат в **большом окне**, реагирует
на **изменения в реальном времени** — без нажатия Queue. Работает
через HTTP-эндпоинт.
