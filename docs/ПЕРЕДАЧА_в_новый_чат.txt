ПЕРЕДАЧА В НОВЫЙ ЧАТ — проект Neron (16.11.2026)
================================================================

КТО И КАК РАБОТАЕМ
- Роман: ComfyUI Desktop, Windows, RTX 5070 Ti 16 ГБ, 48 ГБ ОЗУ, Ryzen 9800X3D. Не программист, английский слабый —
  объяснять просто, по-русски. Работа 3 через 3 («выходные» = его 3 свободных дня).
- Репозиторий: github.com/neron5480-cell/neron-video-minimax-h3-i2v. Ветки: dev — наша кухня; main — витрина,
  там порядок всегда. Публикация в Comfy Registry идёт сама при смене версии в pyproject.toml (сейчас 2.3.0).
- План и история: docs/NERON_Цели_и_достижения.txt (читать первым делом).
- ПРАВИЛА: всё двуязычно RU/EN (русский сверху полностью, английский ниже полностью); минимализм — новичку минимум,
  тонкое за ⚙ экспертом; честные цифры; сначала выслушать (несколько сообщений подряд), «не торопись / запиши, но не
  делай / подожди» — только записать; всё публичное и необратимое — только с согласия Романа; проверенные процессы не
  менять без спроса; каждая нода — в своей папке; всё на живую проверку — архивом в чат; не читать мораль.
- Работаем по фактам: догадка → живой прогон Романа → его глаз → вывод. Учебник ≠ правда (размытие лучше силуэта,
  быстрое внимание давало огрехи и т.д.). Код, проверенный прогонами, не трогать «по учебнику».
- УГОВОР (15.11): модели — официальные (Comfy-Org, авторы), если можно; описания постов короткие; витрины — только
  3D и мультяшный стиль, НИКАКИХ детей ни в каком виде (фото, 3D, мультик, аниме), никакой юной внешности.
- CIVITAI: старый аккаунт заблокировали («раздевает людей» — витрина Swap), Роман удалил его; новый аккаунт neron43,
  Роман написал в поддержку. Swap на Civitai НЕ выкладываем; без слов «face swap / замена лица / нагота»; обложки
  только явно безопасные (одна «смелая» картинка метит весь процесс NSFW).

ЧТО ЕСТЬ (папки в репозитории)
- ComfyUI-NeronH3Swap — 🎭 Замена героя 0.14 (в main и Registry 2.3.0). Клип + фото → тот же клип с человеком с
  фото. Режимы: весь облик / лицо и причёска / только лицо. SAM 3.1, размытие образца (идея Романа), H3 Ref2VA +
  LoRA Akatz + турбо. Умолчания по прогонам 14.11: быстрое внимание ВЫКЛ, «рисовать» = авто (весь облик → весь кадр,
  лицо → только человека). Справка сухая, отказ от ответственности большими буквами в начале.
- ComfyUI-NeronH3Story — длинный ролик до 45 с блоками. В dev (16.11, НЕ проверено вживую, архив отправлен):
  🗂 Картотека (нода NeronH3Cast: до 3 образцов с подписью → вход cast движка → в каждый блок после картинок блока)
  и 🎨 подгонка цвета блоков по стыку (эксперт, color_match 0.3). Тесты на модели: 17/17.
- ComfyUI-NeronStudio — рабочий стол (dev 2026.11.13·14): светлая тема «Светлый Neron» с синевой; плитки иконка +
  название + строка «что делает»; ~330 px плитка, сетка; окошко «Идёт генерация / Готово»; «🏠 Стол» закрывает
  незапущенный процесс без вопроса; процесс со стола — в теме стола; кнопка «🎨» на полосе открывает полную ноду
  Neron Theme панелью (тема запоминается за процессом).
- NeronTheme — темы; studio-light, единый вид нод/групп в режиме стола (только на экране, файл не меняется).
- Остальное: H3 Engine, LTX Engine, Audio Studio, Perception Relay, Restore Studio и др.

БЛИЖАЙШИЕ ДЕЛА
1. Живая проверка Story: картотека + цвет блоков (папку класть отдельно в custom_nodes — пакет свою копию не грузит).
2. Swap 2.0 (кандидаты): вырезка фото по режиму (тогда «весь кадр» безопасен для всех режимов и длинных клипов —
   в «точно» после 5–7 с лицо «мигает» и возвращается оригинал); строка-якорь — описание фото лёгкой моделью
   (~0,5 ГБ, Florence-2/SmolVLM): пол, возраст, волосы, для облика одежда; сначала ручная проверка через hint;
   лёгкий пакет для 8–12 ГБ (minimax_h3_ref2va_pruned_w6a8 + minimax_h3_video_vae_int8_convrot, официальные);
   запас маски в долях головы; обвод на первом кадре (тонкая линия, запас наружу 1–2 %, SAM ведёт); сравнить LoRA
   Pika H3 Flex и Akatz; турбо 0.7 / 12 шагов («лучше держит лицо» по замеру Showrunner).
3. Сверка лица — крошечные модели OpenCV zoo (YuNet + SFace, onnx): «на кадрах N–M лицо не то» — для Swap и Story.
4. Стол: перенос процессов в одном виде; первые процессы — на свои ноды и официальные модели; «⭐ Мои процессы» +
   «＋ На стол»; стол сам предлагает поставить недостающие ноды (с согласия, потом перезапуск); «врач» — паспорт
   машины для автонастроек скорости/памяти; почистить процессы от нод темы (Audio Studio, LTX Engine) — по слову Романа.
5. Картинки на Flux 2 (у Романа ~40 ГБ, 2–3 мин на картинку, «своевольничает» с промптом): нода «Neron Image» с
   автопромтером под Flux 2, образцы картинкой, пакеты лёгкий/обычный/максимум; турбо-LoRA даёт «пластик» — только
   как черновик → чистовик полной моделью по черновику. Роман погоняет модели и пришлёт примеры «не послушался».
6. Фильм для души «Равнодушие» (docs/films/Равнодушие.md — 6 глав, 40 сцен + библиотека кадров): снимать через
   H3 Story с картотекой (парень в капюшоне и респираторе, дрон, город); интерфейс дрона — накладывать при монтаже;
   дети — только намёком или рисунком на стене.
