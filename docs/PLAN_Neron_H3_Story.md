# Neron H3 Story — план (черновик идеи, 05.11.2026)

Статус: **только идея и план. Кода нет.** Всё ниже — договорённости из обсуждения
с автором (neron5480922). Опыт с H3 — его ручные тесты; пометка «гипотеза» = ещё не проверено.

## Цель
Ролик ~30 с (и длиннее) на MiniMax H3 из нескольких блоков по 5–15 с (по умолчанию 10 с),
без «уплывания» внешности, места и звука между блоками.

## Находки автора по H3 (проверены им руками)
1. Последний кадр блока N = первый кадр блока N+1.
2. Картинки на входе — это **полка-источник**, номер = номер слота. Смысл картинке даёт
   **промпт**: «объект идёт в спальню (возьми изображение 2)».
3. Модель берёт с картинки **только то, на что сослались**: героя, спальню, один диван.
   Остальное (пальмы, шезлонги, кафе) выбрасывает. Вырезать ничего не надо.
4. Одежда остаётся как на фото, если в промпте не сказано иное.
5. Героев с разных фото (девушка с пляжа, парень из кафе) модель ставит в одну сцену.
6. Секунда задаётся текстом: «на 5-й секунде девушка улыбается (взять изображение 2)».
   Положение слота по времени не важно.
7. Последний кадр бывает «пустым» (обнялись, лица спрятаны) → следующий блок рисует
   других людей. Лечится: референс внешности (исходная картинка) подаётся **в каждый блок**.
8. Промежуточный кадр = навигатор: фото спальни → объект придёт именно в эту спальню.
9. Аудио-референсы H3 понимает (по словам автора).

## Роли картинок в блоке
| Роль | Что даёт | Откуда |
|---|---|---|
| Старт | откуда продолжаем | блок 1 — исходник; дальше — **реальный** последний кадр прошлого блока |
| Внешность | как выглядит объект | исходная картинка, в **каждый** блок |
| Куда / детали | комната, предмет, цель, финал | промежуточные и последний кадры блока |

Старт следующего блока — реальный кадр видео, не опорная картинка (иначе рывок на стыке).

## Два пути
### Путь 1 — простой (по умолчанию)
- Одна картинка + бриф + длина. Опорных кадров нет. Цепочка «конец → начало», «как повезёт».
- **☑ 🔒 Сохранить внешний вид / Keep appearance — ВКЛ по умолчанию.**
  Исходник подкладывается референсом в каждый блок. В 📖 Справке (RU/EN): для чего,
  почему важно (пустой последний кадр), когда снять (герой по сюжету меняется).

### Путь 2 — эксперт
- **Входы по блокам** (решение автора: человека надо вести, общая полка путает).
  Группы появляются сами по длине ролика: 30 с / 10 с = 3 группы в рамках Neron:
  ```
  ┌ Блок 2 · 10–20 с ──────────────┐
  │ ● старт: авто (конец блока 1)   │
  │ ○ кадр 1  (+ появится ещё)      │
  │ ○ конец блока                   │
  │ [что здесь происходит…]         │
  └─────────────────────────────────┘
  ```
- Слоты кадров растут по мере подключения (как у Qwen-Image 2.1).
- У каждого блока своё короткое поле «что здесь происходит» (своими словами, любой язык).
- Сверху — общий сценарий на весь ролик. Оба уровня необязательны:
  только общий → LLM режет на блоки; только блоки → LLM связывает; оба → поле блока главнее,
  общий даёт контекст; пусто → работа по картинке.
- Расширенные промпты, правка каждой сцены (✏ В правку, как в LTX AutoPrompter).

## Промпты
| Текст | Для кого | Какой |
|---|---|---|
| Строка сцены | человек | по-русски, 1–2 предложения |
| Промпт кадра | генератор картинок | англ., статичный: поза, место, свет |
| Промпт видео | H3 | англ., по секундам, ссылки «(image N)», звук, физика |

Генерация в два прохода:
1. Весь сюжет сразу: строки сцен + **состояние на каждом стыке**.
2. Каждая сцена отдельно: подробный промпт видео (+ промпт кадра). Можно переписать одну сцену.

AutoPrompter со зрением сам составляет **опись** каждой подключённой картинки
(«№2 — гостиная: серый диван, торшер…»), подставляет номера, решает про одежду каждого
объекта («как на фото» / «переодеть») и показывает это в карточке по-русски.
При правке одной сцены — проверка стыков с соседними («сцена 3 не стыкуется — поправить?»).

## Карточки сцен (интерфейс)
```
🎬 Сцена 2 · 10–20 с                      [✏] [🔄]
┌──────────┐  Рыцарь выхватывает меч, шаг вперёд…
│  кадр    │  участвуют: спальня (картинка 2)
│  конца   │  ▸ промпт для модели (эксперт)
└──────────┘
```
Позже в карточку встаёт готовый кусок видео.

## Генератор опорных кадров (необязательный)
- Если человек не подал кадры, движок может нарисовать конец каждой сцены сам —
  правкой исходника (Qwen-Image 2.1 / FLUX 3 Klein / P-H3-Image — выбрать тестом).
- Достаточно нарисовать позу/место; лицо H3 возьмёт из референса внешности.
- Человек видит раскадровку картинками **до** долгой генерации видео и перерисовывает плохие.
- Провод человека главнее автоматики.

## Звук
- Внешний звук — опция, отдельными проводами: речь, музыка, …
- Если ничего не подано:
  - **Музыка:** H3 пишет «No music»; музыка — одним куском на весь ролик
    (MiniMax Music 3 / Audio Studio) поверх. Сложный путь (разделить музыку из блока 1
    разделителем дорожек) — под «эксперт», качество не проверено.
  - **«Звуковая полка» наполняется сама:** хвост звука блока → референс следующего;
    реплики героев вырезаются (Whisper находит место) → «голос героя N» во все следующие
    блоки, где он говорит. H3 берёт до 3 аудио-референсов: 1 — хвост, 2–3 — голоса.
  - **☑ 🔒 Сохранить голоса — ВКЛ по умолчанию.**
  - На стыке — короткий плавный перехлёст (обычный код).

## Устройство на холсте (предложение)
```
[Картинка] [кадры по блокам] ─► 📝 Сценарий ─► 🖼 Кадры ─► 🎬 Видео
```
- Три ноды на одном проводе «история». ComfyUI не перезапускает ноду с неизменными входами →
  поправил кадр 2 — сценарий не пересчитывается. Это и есть «остановки».
- Отдаём готовым процессом (workflow), новичок видит три шага слева направо.
- Видео-нода: **одна H3 по кругу внутри ноды** (провода в круг в ComfyUI нельзя).
  Сначала кодировщик текста по всем блокам → выгрузить; H3 держать между блоками,
  чистить только временные данные; в конце — выгрузить всё.
- Прогресс понятным языком: «Блок 2 из 3, шаг 5 из 8». Готовый блок виден сразу.

## Сохранение и продолжение
В папку проекта на диск: видео и звук каждого блока, полка образцов (голоса, хвосты),
сценарий. → Переделать один блок, не трогая остальные. → Кнопка «продолжить» (+20 с)
хоть на следующий день.
