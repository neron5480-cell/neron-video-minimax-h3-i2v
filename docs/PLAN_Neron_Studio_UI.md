# 🖥 Neron Studio — свой рабочий стол поверх ComfyUI (идея, 06.11.2026)

## Суть (слова автора)
- Отдельный красивый UI поверх ComfyUI: **все наши процессы** в одном месте, не один.
- Сбоку — выбор процесса; выбрал — подгружается наш процесс **со всеми настройками**.
- **Сквозная связка:** результат одного процесса виден следующему. Сгенерировал картинку →
  перешёл в «видео» → эта картинка уже лежит во входе первого кадра.

## Что уже договорено
- Строим только через официальные пути ComfyUI (API очереди, события прогресса, /view, /upload) —
  как и все наши ноды, которые пережили несколько глобальных обновлений без падений.
- Наши процессы не переписываем: Studio подставляет в них картинки/текст/настройки и запускает.
- Настройки — как на нодах: главное видно сразу, остальное за ⚙ экспертом. Двуязычно, стиль Neron.
- Открывается как страница внутри ComfyUI (папка в custom_nodes, адрес вида 127.0.0.1:8188/neron);
  обычный ComfyUI с нодами остаётся рядом.

## Идея «лотка» для сквозной связки
- Общий лоток результатов (картинки, видео, звук, последние кадры) — всё, что сделал любой процесс.
- Входы процессов умеют брать из лотка: «первый кадр ← последняя картинка», «звук ← последний трек»,
  перетаскиванием или автоматически.
- Последний кадр видео → первый кадр следующего ролика (продолжение истории).

## Порядок работы (предложение)
1. Картинка-макет рабочего стола: меню процессов, окна входов, кнопка, прогресс, лоток/галерея.
2. Первый рабочий вариант на 1–2 процессах (например, H3 Story + генерация картинки) со связкой.
3. Подключать остальные процессы по одному: LTX, H3 Engine, Audio Studio, Perception Relay…

## Открытые вопросы к автору

- Для кого в первую очередь: «чайник» (только кнопки) или пульт со входом в ноды?
- Тема: своя тёмная или из Neron Theme?
