# 🎬 Neron H3 One — единый движок MiniMax H3 / single MiniMax H3 engine

> **dev-сборка / dev build.** Проверяется перед выходом в main.

Один ролик MiniMax H3 со звуком (1–15 с). Собран из проверенного в наших движках:
**H3 Engine** (память по этапам, раскодировка с запасным планом), **H3 Story** (модели и автоскачивание,
быстрая LoRA, оформление), **Studio HD** (черновик → чистовик), **H3 Studio** (кэш энкодера,
настоящий первый кадр, обрезка под формат).

Ставится **рядом** со старыми пакетами: у него свои имена нод, маршрутов и событий. Модели и токен
Hugging Face общие — ничего не перекачивается.

## Установка / Install
Папку `ComfyUI-NeronH3One` — в `ComfyUI/custom_nodes`, перезапустить ComfyUI.
Нода: **Neron/H3 → 🎬 Neron H3 One / Единый движок H3**. Нет моделей — окно «📥 Модели» откроется само.

## Режимы / Modes
| Режим | Модель | Шаги | Что важно |
|---|---|---|---|
| 🔥 Экстрим | Fast H3 (если есть) или своя + быстрая LoRA | 8 / 4 | разреженное внимание: vsa (Fast H3) или sol-attn |
| 🚀 Быстро | база + быстрая LoRA | 6 (⚙ 4…10) | ⚙ можно турбо-LoRA, 12 шагов |
| ⚖ Баланс | черновик → увеличение → чистовик | 8 + 3 | ⚙ «чище» — 8 + 6 |
| ✨ Качество | bf16, если лежит | 40 | без LoRA скорости |
| 👑 Максимум | bf16 + энкодер int8 | 50 | образцы в полном качестве |

Своя модель (например, дообученная) никогда не подменяется на Fast H3.

## 🛡 Защита от двоения / Anti-ghosting
LoRA на сжатой модели (int8/fp8) ComfyUI пересжимает со случайным округлением
(`comfy/ops.py → set_weight → requantize_from_float`) — тонкая турбо-LoRA тонет в шуме, отсюда двоение
и артефакты. Если рядом лежит та же модель в bf16 (`…_bf16.safetensors`), нода берёт её сама.
Нет — предупреждает в отчёте.

## ⚡ Ускорение / Speed (⚙)
Только официальные пути ComfyUI, **ничего не устанавливается**:
- внимание: PyTorch (точно) · Sage (если уже стоит) · Kitchen INT8 (мягче деталь);
- разреженное: штатная нода «Model Sparse Attention» — `sol-attn` без дообучения (порог tau) или `vsa` для Fast H3.

Любое ускорение — сравнивать на одном сиде.
