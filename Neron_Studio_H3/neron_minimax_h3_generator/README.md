\# 🎥 Neron MiniMax H3 Generator



\*\*Одна нода, чтобы править всеми. Вся мощь MiniMax H3 в одном комбайне.\*\*

\*\*One node to rule them all. The full power of MiniMax H3 in a single machine.\*\*



\---



\## 📖 О ПРОЕКТЕ / ABOUT



\*\*Neron MiniMax H3 Generator\*\* — это ядро пайплайна Neron Studio. Мы взяли стандартный субграф ComfyUI, который обычно состоит из 30+ нод (загрузчики, сэмплеры, кондишены, LoRA, VAE-декодеры), и спрятали всю эту «лапшу» внутрь одной аккуратной панели.



Нода выполняет полный цикл генерации видео и звука. На выходе вы получаете готовое видео, аудио, последний кадр и точное количество сгенерированных кадров.



\*\*Neron MiniMax H3 Generator\*\* is the core of the Neron Studio pipeline. We took the standard ComfyUI subgraph (usually 30+ nodes of loaders, samplers, conditionings, LoRAs, VAE decoders) and hid all that spaghetti inside one clean panel.



\---



\## ⚙️ ГЛАВНЫЕ ФИШКИ / KEY FEATURES



\*   \*\*Гострабайтер (Go-on-Worker).\*\* Нода не держит память. CLIP выгружается сразу после кодирования промпта, UNET — после сэмплинга, VAE — после декода. Это позволяет генерировать 15 секунд видео на 16 ГБ VRAM без OOM.

\*   \*\*Промпт только извне.\*\* Внутри ноды нет текстового поля. Промпт подается строго через вход `prompt` (обычно от AutoPrompter). Это исключает конфликты.

\*   \*\*Умный VAE-декод.\*\* Если видеопамяти не хватает, нода автоматически подбирает `tile\_size` и уменьшает его при OOM.

\*   \*\*Встроенные слоты LoRA.\*\* До 3-х пользовательских LoRA прямо в ноде.

\*   \*\*Расширение сцены H3.\*\* Не нужно делать апскейл. Киньте портрет 400x500, выберите 21:9, и H3 сама дорисует окружение по бокам.

\## 🎛 РЕЖИМЫ / MODES



\*   \*\*Simple\*\* — видны только главные настройки: Режим, Секунды, Размер, Память.

\*   \*\*Expert\*\* — открываются группы LoRA, Модели и Тонкая настройка (шаги, сид, decode tile).



\### Режимы генерации (MODE)

\*   \*\*Turbo\*\* — 8 шагов. \*\*Полноценная быстрая генерация\*\* (применяется Turbo LoRA). Идеально для слабого железа или когда нужно быстро получить качественный результат.

\*   \*\*Normal\*\* — 20 шагов. Максимальное качество для мощных видеокарт.



\---



\## 📥 ВХОДЫ / INPUTS



\*   \*\*prompt\*\* (обязательно) — текст промпта (строка).

\*   \*\*ref\_image\_0...3\*\* — референсы. Если `ref\_image\_0` не подключен, создастся черный кадр (режим T2V).

\*   \*\*ref\_video, ref\_video\_audio, ref\_audio\*\* — референсы для видео и звука.

\*   \*\*width, height\*\* — размеры. \*\*Важно:\*\* если они подключены, внутренние виджеты размера игнорируются.

\*   \*\*length\_in\*\* — количество кадров (переопределяет виджет SECONDS).



\## 📤 ВЫХОДЫ / OUTPUTS



\*   \*\*video\*\* — готовый видеоряд (IMAGE).

\*   \*\*audio\*\* — сгенерированный звук (AUDIO).

\*   \*\*last\_frame\*\* — последний кадр (удобно для создания бесшовных продолжений).

\*   \*\*frames\_count\*\* — количество кадров (для синхронизации).



\---



\## ⚠️ ВАЖНЫЕ ПРАВИЛА / IMPORTANT RULES



1\.  \*\*Кратность 17.\*\* H3 понимает длину видео только в формате, где `длина % 17 == 5`. Нода делает это автоматически, но помните: максимум для сохранения связности — \*\*15 секунд\*\*.

2\.  \*\*Кратность 32.\*\* Все разрешения (ширина и высота) должны быть кратны 32. Это требование H3.

3\.  \*\*FREE AFTER RUN / ОЧИСТКА ПОСЛЕ.\*\* Включена по умолчанию. После генерации все модели выгружаются из VRAM и RAM. Следующий запуск будет чуть дольше (загрузка с диска), но память будет абсолютно чистой.

\## 📦 УСТАНОВКА / INSTALLATION



1\. Скопируйте папку `neron\_minimax\_h3\_generator` в `ComfyUI/custom\_nodes/`.

2\. Перезапустите ComfyUI.

3\. Нода появится в категории \*\*Neron/H3\*\*.



\*Убедитесь, что у вас скачаны модели H3 (UNET, CLIP, VAE video, VAE audio) и они лежат в стандартных папках ComfyUI `models/`.\*
