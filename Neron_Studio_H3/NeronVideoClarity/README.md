# 🎬 Neron Video Clarity

**Превращает "грязное" видео в чистое. Без апскейла. Без латентного прохода. Только пиксели.**

**Turns "dirty" video into clean video. No upscale. No latent pass. Pure pixels.**

---

## 📖 О ПРОЕКТЕ / ABOUT

**Neron Video Clarity** — это нода для ComfyUI, которая делает **одну вещь хорошо**: убирает дрожание, мерцание, шум и "пластилиновость" с видео, **не меняя разрешения**. Вход 720p — выход 720p, но чище в разы.

**Neron Video Clarity** is a ComfyUI node that does **one thing well**: removes jitter, flicker, noise and "plastic look" from video, **without changing resolution**. Input 720p — output 720p, but dramatically cleaner.

### ✅ Что делает / What it does

- **Стабилизация** / Stabilization — убирает дрожание деталей между кадрами
- **Motion compensation** — учитывает движение, не размазывает руки и лица
- **Дефликер** / Deflicker — убирает мерцание яркости
- **Цвет** / Color — яркость, насыщенность
- **Резкость** / Sharpness — усиливает края
- **Объём** / Local contrast — даёт "плотность" картинке
- **Детализация** / Detail boost — усиливает мелкие текстуры (ресницы, ворс, поры)
- **Интерполяция** / Interpolation — RIFE x2/x4 fps (в правильном порядке!)
- **Звук** / Audio — громкость, EQ (басы, середина, верха), баланс
- **Финальный кадр** / Last Frame — выдает уже очищенный последний кадр (идеально для склейки видео без швов).

### ❌ Чего НЕ делает / What it does NOT do

- **Не добавляет пиксели** — это не апскейлер
- **Не дорисовывает детали** — это не латентный проход
- **Не заменяет Topaz Video AI** — но работает быстрее и на "вёдрах"
- **Не меняет fps** — если не включить интерполяцию
- **Не трогает аудио** — если не включить аудио-обработку

## 📦 УСТАНОВКА / INSTALLATION

1. Скопируй папку `NeronVideoClarity` в `ComfyUI/custom_nodes/`
2. **Полностью перезапусти ComfyUI** (не просто Refresh!)
3. Нода появится в категории **Neron/Video**

**Важно:** имя папки должно быть **без пробелов** — `NeronVideoClarity`, а не `Neron Video Clarity`.

## 🚀 БЫСТРЫЙ СТАРТ / QUICK START

Схема подключения:

[Load Video] --- [Neron Video Clarity] --- [Video Combine]

**Как подключить:**

1. Выход `IMAGE` из Load Video подключи на вход `image` ноды Clarity
2. Выход `AUDIO` из Load Video подключи на вход `audio` ноды Clarity (опционально)
3. Выход `image` из Clarity подключи на вход `images` ноды Video Combine
4. Выход `audio` из Clarity подключи на вход `audio` ноды Video Combine
5. Выход `last_frame` можно использовать для старта следующей сцены, чтобы избежать цветового скачка.
6. Выбери пресет и нажми Queue

**Если сомневаешься какой пресет** — начни с `📼 Хроника` для старого видео или `🤖 AI Gen` для сгенерированного.

## ⚠️ ГРАБЛИ / PITFALLS

- **RIFE должен идти ПОСЛЕ стабилизации.** У нас так и есть — не меняй порядок пайплайна.
- **SHARPEN 0.5+** даёт белые ореолы на контурах.
- **DETAILS 0.5+** даёт "песочность" на коже.
- **VOLUME +12 дБ** и выше = клиппинг (треск на пиках).
- **Слишком большое STAB WINDOW** = "залипание" движения.
- **INTERPOLATE на сыром видео** = вернёт дрожание. Сначала стабилизируй, потом интерполируй.
- **VHS_LoadVideo падает на видео без аудио** — это баг VideoHelperSuite, не наш. Обнови пак или используй видео с аудио-дорожкой.

## 🔬 КАК ЭТО РАБОТАЕТ / HOW IT WORKS

Обработка идёт в семь стадий, строго в таком порядке:

1. **Стабилизация** (motion-compensated) — выравнивает детали между кадрами
2. **Дефликер** — убирает мерцание яркости
3. **Цвет и контраст** — базовые правки (яркость, насыщенность, объём)
4. **Резкость** (unsharp mask) — усиление краёв
5. **Детализация** (edge-aware detail boost) — микро-текстуры
6. **Интерполяция RIFE** — ОПЦИОНАЛЬНО, на выходе (x2/x4 fps)
7. **Аудио** — ОПЦИОНАЛЬНО, passthrough или EQ

**Ключевое 1:** motion compensation выравнивает соседние кадры по движению, а не усредняет их вслепую. Это то, что отличает Clarity от обычного "покадрового шумодава".

**Ключевое 2:** RIFE интерполирует **уже стабилизированные** кадры. Если поставить RIFE до стабилизации — он внесёт свой джиттер, который потом невозможно вылечить. Это была самая большая ошибка на ранних версиях.

**Ключевое 3:** чанкинг с crossfade. Длинное видео режется на куски по `CHUNK SIZE`, каждый обрабатывается отдельно, а стыки сглаживаются через градиент — швов не видно.

## 🐛 ИЗВЕСТНЫЕ ПРОБЛЕМЫ / KNOWN ISSUES

- **RIFE не найден:** если в логе `RIFE not found` — установи `ComfyUI-Frame-Interpolation`. Иначе используется fallback `warp` (быстрее, но качество интерполяции ниже).
- **OOM на длинном видео:** уменьши `CHUNK SIZE` или `VRAM PRESET`.
- **Видео без аудио падает в VHS_LoadVideo:** это чужая проблема. Добавь пустую аудио-дорожку или обнови пак.
