# 🤖 Neron AutoPrompter (LLM + Camera Director)

**Твой личный режиссёр и сценарист. Превращает короткую мысль в идеальный промпт для MiniMax H3.**
**Your personal director and screenwriter. Turns a short brief into a perfect MiniMax H3 prompt.**

---

## 📖 О ПРОЕКТЕ / ABOUT

**Neron AutoPrompter** — это "мозг" пайплайна Neron Studio. Нода объединяет в себе две роли: 
1. **Мультимодальный LLM-режиссёр** (смотрит на картинки и дописывает детали).
2. **Оператор** (рассчитывает правильную длину видео и управляет камерой).

Вам больше не нужно писать огромные промпты вручную. Достаточно закинуть стартовый кадр, написать пару слов (например, "девушка улыбается"), выбрать ракурс — и LLM сама сгенерирует технически сложный промпт, который H3 поймет идеально.

**Neron AutoPrompter** is the "brain" of the Neron Studio pipeline. This node combines two roles:
1. **Multimodal LLM Director** (analyzes images and adds missing details).
2. **Camera Operator** (calculates correct video length and controls the camera).

---

## 🎭 ТРИ РЕЖИМА РАБОТЫ / THREE MODES

Нода умеет работать в трех режимах (виджет `workflow_mode`):

1. **[LLM] Autoprompter** — LLM смотрит на подключенные картинки (`image_0`, `image_1` и т.д.) и ваш текст, после чего выдает готовый промпт. Это основной режим.
2. **[LLM] Text Only** — LLM работает только с вашим текстом. Картинки игнорируются (если нужно сэкономить память).
3. **[Manual]** — LLM не запускается. Текст берется из поля `manual_prompt`. Режим для тех, кто хочет написать всё сам, но пользуется калькулятором кадров.

---

## 🎥 КАМЕРА / CAMERA OPERATOR

Нода сама считает кадры (кратно 17) и управляет камерой. 
Доступные ракурсы (`camera_mode`):
*   **AUTO** — LLM сама решает, как смотреть на сцену.
*   **FRONT, LEFT, RIGHT, BACK** — фиксированные ракурсы.
*   **TOP, BOTTOM** — верхний и нижний ракурсы.

Выход `frames_count` автоматически синхронизируется с нодой **Neron MiniMax H3 Generator**, так что вам не нужно вручную считать секунды.

## ⚙️ УСТАНОВКА И ЗАВИСИМОСТИ / INSTALLATION

Нода является "оберткой" над движком **ComfyUI-LLM-text-processor**. 
1. Убедитесь, что папка `ComfyUI-LLM-text-processor` установлена в `custom_nodes`.
2. Скачайте GGUF-модель (рекомендуется **Qwen 3.5 9B** или **Qwen 2.5-VL**) и положите её в `ComfyUI/models/LLM/`.
3. Для работы с картинками (Vision) обязательно скачайте `mmproj` файл и положите его туда же.
4. Поместите системные промпты (например, `H3_NSFW_Engine 1.txt`) в папку `prompts` рядом с нодой (или в `models/LLM/prompts`).

*Для глубокой настройки LLM (temperature, top_k, gpu_layers) читайте README в папке `ComfyUI-LLM-text-processor`.*

## 📥 ВХОДЫ / INPUTS

*   **prompt_in** — ваш короткий текст (мысль).
*   **image_0, image_1, image_2** — референсы (стартовый кадр, персонажи, стиль).
*   **last_frame** — (опционально) финальный кадр для режимов морфинга.

*(В Expert режиме появляются виджеты выбора модели, системного промпта, параметров сэмплинга и `UNLOAD AFTER RUN`).*

## 📤 ВЫХОДЫ / OUTPUTS

*   **minimax_prompt** — готовый, технически выверенный промпт для H3.
*   **frames_count** — идеальное количество кадров (кратно 17).
*   **storyboard_json** — JSON с раскадровкой (если нужно передать в другие ноды).

---

## ⚠️ ГРАБЛИ / PITFALLS

*   **UNLOAD AFTER RUN** — по умолчанию `true`. После генерации промпта LLM выгружается из VRAM, чтобы освободить место для H3 Generator. Если выключить, следующий запуск будет быстрее, но H3 может упасть с OOM (Out of Memory).
*   **Если LLM пишет бред** — проверьте системный промпт. Иногда модели нужен более жесткий "пинок" (как в `H3_NSFW_Engine 1.txt`).
*   **Модель не видит картинку** — убедитесь, что в Expert Mode выбран `mmproj` файл.
